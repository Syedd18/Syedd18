### 03 — [Pothole Detection System](https://github.com/Syedd18) &nbsp;`Computer Vision` `Transfer Learning` `FastAPI`

> **Deep Learning Road-Defect Classifier**

A computer vision classification system built with transfer learning on **MobileNetV2** and **EfficientNetB0**, reaching **92% classification accuracy**. Preprocessing, normalization, and augmentation expanded the dataset by **2,000+ images** for better robustness and generalization.

| Concern | Implementation |
|---|---|
| Modeling | Transfer learning with MobileNetV2 and EfficientNetB0 (TensorFlow / Keras) |
| Data | Image preprocessing, normalization, and data augmentation |
| Deployment | FastAPI REST API + Tkinter application for real-time inference with confidence scores |

`Python` &nbsp; `TensorFlow` &nbsp; `Keras` &nbsp; `MobileNetV2` &nbsp; `EfficientNetB0` &nbsp; `FastAPI`
